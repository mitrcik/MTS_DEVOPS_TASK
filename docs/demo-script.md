# Сценарий видео-демонстрации (≤ 5 минут)

> Видео — **реальная запись экрана** работающего стенда. Синтетическое видео или видео, созданное
> нейросетью, не подходит: так сказали организаторы на консультации. Они же разрешили вырезать при
> монтаже долгие этапы: `make up` (~3–4 мин на холодном старте) и стадии CI. Место каждой склейки
> отметьте подписью «монтаж: ожидание N с вырезано».
>
> **Статус: видео ещё не записано. Это отдельный артефакт команды.**

## Подготовка (вне записи)

```bash
git clone <URL-репозитория> mts-devops && cd mts-devops
make up                 # заранее, чтобы образы были в кэше; затем make down && make up на записи
make credentials        # пароль Grafana (не показывать в кадре)
```

Что открыть перед записью:

- терминал с крупным шрифтом;
- браузер с Grafana `http://grafana.localhost:8080`: дашборд «MTS DevOps — демо-API», обновление
  каждые 5 s;
- вкладку Alertmanager `http://alertmanager.localhost:8080`.

Демо-профиль: окно gate — 30 с, у алертов `for: 30s`. Gate — автоматическая проверка релиза по
метрикам. Настройки лежат в `.env` и `observability/files/rules`.

## Если что-то пошло не так во время записи

- Docker Hub отвечает 429 (слишком много запросов) — настройте зеркало по `docs/troubleshooting.md`
  и перезапустите `make up`.
- Алерт уже в состоянии firing до `make demo-alert` — дождитесь resolved. Скрипт сам не начнёт
  демонстрацию, пока алерт активен.
- Стенд «грязный» после экспериментов — выполните `make down && make up` (секреты сохраняются).
