# Сценарий видео-демонстрации (≤ 5 минут)

> Видео — **реальная запись экрана** работающего стенда (без синтетических/нейросетевых видео
> [09:56]). Долгие этапы (`make up` ~3–4 мин на холодном старте, стадии CI) можно вырезать при
> монтаже [07:23, 27:11] — места склеек обозначить подписью «монтаж: ожидание N с вырезано».
> **Статус: видео ещё не записано — это отдельный артефакт команды.**

## Подготовка (вне записи)

```bash
git clone <URL-репозитория> mts-devops && cd mts-devops
make up                 # заранее, чтобы образы были в кэше; затем make down && make up на записи
make credentials        # пароль Grafana (не показывать в кадре)
```

Окна: терминал (крупный шрифт), браузер с Grafana `http://grafana.localhost:8080`
(дашборд «MTS DevOps — демо-API», обновление 5 s), вкладка Alertmanager `http://alertmanager.localhost:8080`.
Демо-профиль: окно gate 30 с, `for: 30s` у алертов (`.env`, `observability/files/rules`).

## Если что-то пошло не так во время записи

- Docker Hub 429 — см. `docs/troubleshooting.md` (зеркало) и перезапустите `make up`.
- Алерт уже firing до `demo-alert` — подождите resolved (скрипт сам откажется начинать).
- Стенд «грязный» после экспериментов — `make down && make up` (секреты сохраняются).
